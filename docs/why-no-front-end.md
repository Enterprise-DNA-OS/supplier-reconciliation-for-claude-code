# Why this desk has no front end

The work is comparing dated records, explaining differences and preparing a review pack. A coding agent runs those jobs from plain language over one private database. Static HTML views show the result without a running web application.

A screen gives a supplier a self-service upload path, and gives staff live notifications, interactive filtering and a shared sign-in. This base has none of those. It also has no mobile capture, offline merge, OCR service, automatic supplier emails, live ERP feed or bank connection. It starts from checked CSV open-item snapshots and produces local drafts and review documents.

Enterprise DNA can build a portal, feed, document extraction step, authenticated approvals or a different stack into a custom installation. Those are separate deliverables. The free base has one trusted operator context per business. Review labels do not replace access control.

Static documents become stale when the data changes. Re-render before using them. Original source evidence and the accounting ledger remain authoritative for accounting decisions. No match authorises a payment.
